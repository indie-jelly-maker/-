생물과 탄소 저장 · 80분

생물과 탄소 저장

생물의 다양성을 발견하고, 생물에서 비롯된 물질의 일부가 갯벌 흙에 남는 과정을 설명한다.

준비

학생용 웹앱, 기기와 펜 또는 종이·색연필. 처음 그림과 나중에 더한 생물을 구별할 색을 준비한다. 사진은 생물 관찰 예시이며 인천 현장 사진이 아님을 확인한다.

이번 시간에 남길 것

처음 그림 → 새 생물과 역할 추가 → 탄소가 흙에 남는 과정 한 문장. 종이에 그린 경우 활동지와 그림을 함께 보관한다.

수업 흐름 · 활동 75분 + 휴식 5분
시간활동교사의 안내
0–10분생각 꺼내기“갯벌에는 누가 살까요? 큰 나무가 많지 않은데도 탄소와 관련이 있을까요?” 정답을 먼저 설명하지 않고 이유를 듣는다.
10–40분생물 그리기아는 생물 그리기 10분 → 규조류·칠면초·칠게 사진 관찰 10분 → 다른 색으로 새 생물과 특징 추가 10분. 미세조류는 현미경 사진임을 짚는다.
40–45분휴식화면에서 눈을 떼고 쉰다.
45–65분탄소 저장 과정‘이산화탄소 → 생물이 만든 유기물 → 일부가 흙에 남음’을 그림으로 따라간다. 일부는 분해되어 다시 순환함을 함께 설명한다. 분자 모형은 용어가 헷갈릴 때만 활용한다.
65–80분내 말로 설명잘못된 문장 고치기, 짝에게 설명하기, 1차시 생각 담기. 2차시 질문 “흙에 탄소가 있다는 것은 어떻게 확인했을까?”로 마무리한다.

탄소 저장 과정 설명

이산화탄소공기 중·물속의 탄소
→
생물의 유기물미세조류·식물의 광합성
동물은 먹이로 얻음
→
갯벌의 흙묻힌 유기물의 일부가 남음
일부는 분해·순환

개념을 단순화한 흐름이다. 밖에서 유입되는 유기물도 있으며 모든 탄소가 오래 보존되는 것은 아니다.

발문과 예상 반응

“게와 규조류는 탄소를 얻는 방법이 같을까?”

“둘 다 광합성을 해요”라고 하면 사진과 설명을 다시 읽게 한다. 규조류는 광합성을 하고, 게는 먹이를 통해 유기물을 얻는 차이를 연결한다.

“흙에 이산화탄소 기체가 그대로 갇혀 있을까?”

‘기체를 가둔다’는 표현을 ‘생물에서 비롯된 유기물의 일부가 묻혀, 그 안의 탄소가 남을 수 있다’로 수정하도록 돕는다.

가르칠 범위

탄소는 여러 물질에 들어 있는 원소이고, 이산화탄소에는 탄소와 산소가 들어 있다는 정도로 다룬다. 원자 수·화학식 암기를 목표로 삼지 않는다.

‘흡수’는 대기·물의 탄소를 생물의 유기물에 포함시키는 과정과, ‘저장’은 탄소가 어떤 곳에 남아 있는 상태와 연결한다. 연간 흡수량 계산이나 저장량 순위는 필수 활동에서 제외한다.

관찰할 증거
새로 그린 생물의 이름보다 “어떤 역할 때문에 더했는가”를 듣는다. 학생이 말한 과정에서 ‘일부’, ‘유기물’, ‘흙에 남음’의 관계를 확인한다. 용어만 따라 읽었다면 그림을 가리키며 다시 설명하도록 한다.

위성영상과 갯벌 변화 · 80분

위성영상과 갯벌 변화

Sentinel-2를 탐색하고 Landsat 기반 갯벌 분류지도와 인천 해안 영상을 비교한다. 공식 면적 통계와 흙 연구를 함께 읽고 근거를 정리한다.

준비

기본 사례는 인천 해안이다. Sentinel-2 전국 지도, Landsat 기반 갯벌 분류지도와 타임라인, 1981·2013 영상, 2003–2023 전국 통계, Lee 외(2021) 흙 조사 화면을 미리 연다. 영상의 장소·촬영일·조사 범위를 확인한다.

이번 시간에 남길 것

영상에서 확인한 변화, 통계에서 읽은 연도와 수치, 흙 연구의 조사 방법. 마지막에는 자료 하나를 선택해 ‘확인한 사실 → 내 생각과 이유’를 기록한다.

수업 흐름 · 활동 75분 + 휴식 5분
시간활동교사의 안내
0–10분Sentinel-2 탐색선생님과 정한 지역을 학생이 직접 찾고 이동·확대한다. 해안·물길·주변 시설을 관찰하고 위치와 관찰을 기록한다.
10–30분Landsat 갯벌 비교Landsat 기반 Murray 갯벌 분류지도에서 같은 지역의 두 시기를 비교한다. 왼쪽 기준 시기를 고정하고 오른쪽을 재생한다. 분포와 범위가 달라진 위치를 표시하고 기록한다.
30–40분인천 해안 영상 비교1981·2013 Landsat 영상에서 같은 섬·해안을 찾는다. 학생의 관찰 뒤 USGS의 지역 변화 설명을 읽고 구분한다.
40–45분휴식관찰 기록을 담고 쉰다.
45–55분공식 면적 통계전국 갯벌 면적의 연도·단위를 읽고 처음과 마지막 조사 값을 비교한다. 분류지도 화면과 공식 통계의 조사 방법·범위를 구별한다.
55–70분갯벌 흙 조사퇴적물을 채취하고 층별로 분석해 유기탄소를 확인한 과정을 읽는다. 위성영상에서 흙 속 탄소를 직접 본 것이 아님을 구별한다.
70–80분근거 정리탐색·비교·통계·연구 중 자료 하나를 골라 확인한 사실과 내 생각의 연결을 기록한다. 3차시에 쓸 근거를 고른다.

위성영상에서 할 질문

“같은 섬을 찾았니? 무엇이 연결되거나 새로 보이니?”

“밝은 곳이 줄었어요”라면 색만으로 갯벌 여부를 단정하지 않도록 한다. “공항 때문에 전부 사라졌다”라면 영상에서 보이는 사실과 별도 설명을 구분한다.

통계에서 할 질문

“이 숫자는 인천일까, 전국일까? 중간의 매년 모습도 알 수 있을까?”

5개 조사 시점의 전국 합계임을 확인한다. 모든 지역에서 같은 변화가 있었다고 결론 내리지 않는다.

흙 연구에서 할 질문

“흙 색만 보고 탄소가 있다는 것을 알 수 있을까?”

채취·분석이라는 확인 방법을 답에 포함하도록 돕는다. 여기서 ‘지역’은 조사한 갯벌 지역이며 일반 육지와 갯벌을 비교한 표가 아니다.

자료를 연결할 질문

“갯벌 면적이 줄었으니 탄소가 이만큼 나왔다고 말할 수 있을까?”

면적 감소 자료와 흙의 저장 기능을 정성적으로 연결한다. 면적 변화와 저장량을 곱해 실제 배출량이라고 제시하지 않는다.

자료 연결 설명
“갯벌에는 생물이 살고 흙에 탄소가 저장되는 기능도 있다. 우리는 영상과 통계로 공간의 변화를 보고, 흙 연구로 눈에 보이지 않는 기능을 확인했다.” 자료마다 공간·시기가 다르므로 같은 장소의 인과관계를 직접 증명한 것처럼 연결하지 않는다.
탐구 지역을 교사가 정할 때

이 파일의 기본 비교 사례는 인천이다. 선택 이유는 과거·이후의 비교 영상과 기관 해설이 함께 있기 때문이다. 전국 지도는 자유롭게 움직일 수 있지만, 지도에서 고른 모든 지역의 비교 자료가 자동으로 제공되는 것은 아니다.

새만금·순천만·학교 주변을 택하려면 해당 지역의 비교 가능 영상, 촬영 시기, 지역 설명을 별도로 준비하고 2차시 관찰 질문을 조정한다. 전국 통계나 21곳 갯벌 연구를 선택 지역에서 직접 측정한 값처럼 사용하지 않는다. 현재 버전에는 교사 설정을 학생 기기로 자동 배포하는 기능이 없다.

Landsat 기반 갯벌 비교를 지도할 때

2차시의 필수 비교 활동이다. 같은 지역을 같은 확대 수준에서 비교하고 범위가 달라진 부분을 표시한다. Murray Global Intertidal Change v1.1은 Landsat 기반 갯벌 분류자료로, 1984–2016년의 11개 3년 기간을 보여 준다. 영상 한 장의 색상이나 매년 면적을 직접 표시한 것이 아니다.

왼쪽은 기준 시기, 오른쪽은 재생 시기다. 동일한 시야에서 시작·끝 시기를 번갈아 보며 분포 차이를 관찰한다. 색이 없다는 이유만으로 갯벌 소멸을 확정하지 않는다. 정량적 감소는 공식 통계로 읽고, 분류지도 화면의 픽셀 수를 면적으로 계산하지 않는다.

안내판 제작 · 80분

안내판 제작

모둠별 종이 안내판을 제작하고 사진을 패들렛에 공유한 뒤, 친구의 질문과 의견을 바탕으로 설명을 수정한다.

준비

모둠별 A3 종이, 연필·색연필·사인펜, 풀·가위, 필요한 자료 출력물, 촬영 기기, 교사가 준비한 패들렛 게시판 주소 또는 QR. 수업 전에 사진 게시와 댓글 사용 가능 여부를 확인한다. 화면은 자료를 참조할 때만 사용한다.

제작 조건

읽을 사람, 전할 말, 뒷받침 자료, 그림과 설명, 출처가 드러나야 한다. 배치는 자유롭게 한다. 모둠별 종이 안내판과 개인 설명을 별도로 남긴다.

수업 흐름 · 활동 75분 + 휴식 5분
시간활동교사의 안내
0–10분메시지·근거 선택누구에게 무엇을 알릴지 정한다. 모은 기록에서 주장을 뒷받침할 자료를 선택한다.
10–20분종이에 구상A3 종이에 연필로 배치를 정한다. 자료·설명·그림이 연결되는지 모둠 안에서 점검한다. 온라인 구상안 제출은 요구하지 않는다.
20–50분안내판 제작문장을 짧게 다듬고 그림과 출처를 넣는다. 자료의 숫자를 장식처럼 붙이지 않고 메시지와 연결하게 한다.
50–55분휴식제작 도구를 정리하고 쉰다.
55–70분사진·패들렛 공유·의견사진 촬영·패들렛 게시 5분 → 짝 모둠 게시글에 질문·의견 남기기 5분 → 의견 확인·설명 수정 5분. 게시글에 모둠 이름, 사진, 메시지와 근거를 포함한다.
70–80분개인 설명·보관자료 하나로 보전의 중요성을 혼자 설명한다. 수정 내용과 이유를 기록한다. 패들렛 공유를 확인하고 종이 산출물과 전체 기록 파일을 보관한다.

친구에게 줄 질문

“어떤 말이 가장 잘 전해졌니?”
“그 말을 뒷받침하는 자료는 어디에 있니?”
“설명을 더 듣고 싶은 부분은 무엇이니?”

‘예쁘다’만으로 끝나면 내용에 관한 질문으로 되돌린다. 친구가 오해한 문장을 고치거나 그림에 연결선을 더하는 수정도 의미 있는 개선이다.

STEAM의 설계·개선이 드러나려면

종이 안내판을 단순 꾸미기 결과로 끝내지 않는다. 안내판을 볼 사람과 전달 목적을 정하고, 제작 조건에 맞춰 구성한 뒤, 친구의 반응으로 표현을 수정하게 한다.

제작 전 디지털 동료 평가를 없애더라도 ‘목적 설정 → 구성 → 제작 → 반응 확인 → 개선’은 종이 활동과 수업 대화에서 유지할 수 있다.

수집할 자료
패들렛에 공유한 안내판 사진·모둠별 근거 설명·친구 의견, 모둠이 고친 부분과 이유, 학생 개인의 근거 기반 설명. 게시글에는 모둠 이름·사진·전달 내용·사용한 근거를 포함한다. 제작 예시와 실제 학생 산출물을 구별해 보관한다. 연구용 수집·촬영·공유는 기관의 동의와 연구 절차에 따른다.
디지털 구상·피드백 단계에 대한 운영안

필수 웹앱 절차에서는 제외했다. 80분 안에서 종이 구상과 실물 제작 시간을 확보하기 위해서다. 다만 오개념을 그대로 옮기는 모둠은 교사가 제작 중 짧게 점검한다. 완성 후 사진 촬영·패들렛 공유·내용 피드백·수정은 유지한다. 연구에서 설명의 수정 과정을 볼 수 있도록 ‘바꾼 부분과 이유’ 기록은 남긴다.

  • 전국 지도는 인터넷이 필요하다. 연결이 없어도 내장 비교 영상·그림판·통계·설명은 사용할 수 있다.
  • 3차시에 필요한 종이와 출력물을 미리 준비한다.

교사용과 학생용 HTML을 같은 폴더에 두면 위의 ‘학생용 열기’ 링크를 사용할 수 있다. 각각의 파일은 따로 열어도 작동한다.

기록을 어떻게 보관하나?

학생용 ‘나의 기록’에서 모둠 이름을 입력하고 전체 기록 내려받기로 JSON 파일을 저장한다. 담은 근거, 그림, 이번 차시 입력 내용이 포함된다. 이어서 작업할 때 ‘기록 불러오기’를 사용한다.

기기 안 임시 저장만으로는 다른 컴퓨터로 옮길 수 없다. 새 파일명·다른 브라우저에서 기존 내용이 보이지 않을 수 있다. 안내판 사진은 교사가 안내한 패들렛에 공유하고, 종이 산출물은 교사가 별도로 모은다. 웹앱에는 서버 제출이나 자동 채점 기능이 없다.

수업과 연구의 구별

이 자료는 4학년·3차시 프로그램의 적용을 돕는 교사용 안내서다. 수업 실행과 교육 효과의 검증 결과를 담은 보고서가 아니다. 개인·모둠 기록은 자료 해석과 설명 양상을 살펴보는 근거이며, 그 자체가 표준화된 융합인재소양 검사를 대신하지 않는다.

중·고등학교 확장, 심화 탄소 계산, 글쓰기 자동 평가·API 기능은 현재 프로그램에 포함하지 않는다.
